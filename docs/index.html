Summarize anything

AI Text Summarizer is a lightweight command-line tool that turns long documents, notes and transcripts into clean summaries using the Claude API.

View on GitHub Get Started 
$ pip install -r requirements.txt
$ export ANTHROPIC_API_KEY="sk-ant-..."
$ python summarizer.py file report.txt --bullets

• Revenue grew 18% QoQ driven by enterprise plans
• Churn dropped to 2.1%, lowest in company history
• ...

📄 Files & pipes

Summarize .txt/.md files or pipe any text through stdin.

🎨 4 styles

Bullets, brief, detailed reports, or TL;DR — your call.

📏 Length control

Cap summaries with --max-words. Save with --output.

🪶 Zero bloat

One Python file, one dependency. No servers, no frameworks.
